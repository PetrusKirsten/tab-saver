# Tab Saver

A lightweight Chrome extension for saving, exporting and restoring tab sessions.

## Current features

- Export tabs to TXT, CSV and JSON
- Restore sessions from TXT, CSV and JSON
- Preserve tab order
- Preserve multiple windows
- Preserve pinned and active tabs
- Restore to normal or incognito windows
- Ignore selected URLs during restoration
