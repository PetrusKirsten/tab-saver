# Changelog

## [0.4.0] - 2026-10-13

First formally versioned release of Tab Saver.

### Added
- Export to TXT, CSV and JSON
- Restore from TXT, CSV and JSON
- Current window / all windows export scope
- Configurable domain ignore list
- Normal and incognito restoration

### Improved
- Preserve multiple windows
- Preserve tab order
- Preserve pinned tabs
- Preserve active tabs
- Backward compatibility with legacy TXT backups
